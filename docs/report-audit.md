# Відповідність програми звіту Лаб №4

Звірка від 25.11.2026. Актуалізований звіт описує MathHub MVP Fix станом на 25.11.2026, включно з окремими сторінками курсів, викладачів, груп і оплат. Цей документ пояснює доступ до функцій та межі перевірки. Він не є твердженням про завершення всіх FR/NFR.

| Що описано у звіті | Де перевірити на сайті | Фактична межа |
|---|---|---|
| Реєстрація, вхід, вихід | Мій кабінет → Реєстрація; кнопка Вийти | Немає відновлення пароля або редагування профілю |
| Діагностика 15–20 завдань | Кабінет учня → вибір контексту → Почати діагностику | Навчальний банк, не педагогічна сертифікація |
| Збережений MathScore і ранг | Кабінет після тесту; оновлення сторінки | Бал не є відсотком правильних відповідей |
| Продовження тесту | Оновити вкладку після кількох відповідей | Потрібна активна сесія або повторний вхід |
| Курси | Курси в головному меню | Три демонстраційні курси; не реальний набір на заняття |
| Підбір групи та резерв | Групи та записи → курс → розклад → Зарезервувати місце | Потрібні акаунт учня та MathScore; група обирається алгоритмом |
| Мої записи та місткість | Групи та записи → Мої записи | Показує власний запис, короткий номер групи, стан та лічильники; чужі профілі закриті |
| Тестова оплата резерву | Оплата → Оплата резерву групи або кнопка у записі | Підтверджує Enrollment, але не відкриває відеоурок |
| Скасування та прострочення | Скасувати резерв; після 15 хвилин — Оновити | Скасування Active-запису через UI не реалізовано |
| Батьківське підтвердження | Кабінет батьків → Тестова пошта → Підтвердити зв’язок | Локальна пошта Development; зовнішні листи не надсилаються |
| Оплата для дитини | Кабінет пов’язаних батьків → записи дитини | Учень до 16 років не може сам підтвердити оплату |
| Адміністрування завдань | Вхід локального адміністратора → банк | Лише банк питань; не керування всією платформою |
| Повторна діагностика | Серверне правило 30 днів | Кнопки повторного тесту після результату в UI поки немає |
| Learning, Gamification, Notifications | Вихідний код модулів | Це основа структури, а не готові уроки, XP, стріки й зовнішні сповіщення |
| Викладачі | Наші викладачі | Два профілі з БД, надані імена/фото/біографії; без розкладу та особистих кабінетів |

## Два сценарії оплати

**Оплата резерву** змінює вже створений запис у групу. Шлях: діагностика → Групи та записи → резерв → Оплата → підтвердження. Резерв чинний 15 хвилин. Історія оплат резервів доступна власнику, а батькам — щодо підтверджено пов’язаних дітей.

**Демонстрація без групи** описана в актуальному звіті Лаб4, розділ 8.3. Шлях: Оплата → вибір курсу → Успішна або Відхилена оплата. Діагностика не потрібна. Запис у billing.demo_checkouts зберігає суму з БД, назву курсу, час і статус. Цей сценарій не створює Enrollment, не займає місця та не надає доступ до навчання. Повтор того самого requestId не створює другу квитанцію; зміна даних з тим самим ключем дає конфлікт.

Усі платежі mock. Банківські реквізити не збираються, реальні кошти не списуються.

## Перевірено після змін

Через браузер пройдено реєстрацію, успішну й відхилену демооплату, оновлення історії, повну діагностику з відновленням після 5 відповідей, резервування групи та оплату зі збереженням квитанції. Через HTTP перевірено повтор платежу, конфлікт ключа, відмову без сесії та порожню історію для іншого користувача. Перевірено сторінки на ширині 390 px без горизонтального переповнення та desktop 1920 px. Наявність двох викладачів і завантаження фотографій перевірено через сайт.

Попередні сценарії батьків, адміністратора та конкурентного підбору описані у review.md; вони не видаються тут за новий повний регресійний набір. Формальні тести, навантажувальні вимірювання та production-готовність не заявляються.

## Актуалізація звіту

Word і PDF оновлено під поточну реалізацію: додано сторінки, профілі викладачів, два сценарії оплати, історію квитанцій, таблиці teachers і demo_checkouts та нові міграції. Оновлено навігацію, демонстраційні екрани, сценарій захисту й результати перевірки. Реальні платежі, уроки, кабінет викладача та аналіз помилок за темами не заявляються як готові.
