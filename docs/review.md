# Самоперевірка базової структури

Це індивідуальна самоперевірка автора; незалежне рев’ю іншою людиною не проводилося.

- Domain не посилається на ASP.NET Core, EF Core або UI.
- MathScore має діапазон 0–100 та таблицю 6 рангів / 18 підрангів зі специфікації.
- EloScoringEngine відокремлений від стану сесії та HTTP; кроки K = 8 / 4 / 2.
- TestSession захищає версію, повтор питання та повтор requestId; завершення за правилами 15–20 завдань.
- CohortGroup обмежує суму активних записів і чинних резервів п’ятьма місцями, враховує знімки балів у Δ.
- ActiveCount і стан обчислюються з актуальних записів. Історичні Enrollment зберігаються без загального ліміту 5.
- Доменна перевірка не замінює блокування PostgreSQL: транзакційна реалізація репозиторію залишається роботою Лаб №5.
- Відсутній незахищений endpoint для запису чи зміни особистих даних; поточний API повертає тільки демонстраційний розрахунок.
- У репозиторій не додаються секрети, node_modules, bin та obj.
- Перевірка збірки й запуску не є звітом про повну валідацію вимог Лаб №6.

## Дизайн

Початковий напрям: Cambridge.ua (структура освітньої вітрини), палітра й логотип користувача. Макет і тексти створені для MathHub; статистика чужої школи, викладачі, ціни та відгуки не копіюються. Логотип наданий у PNG, тому конвертація з JPEG не потрібна.
