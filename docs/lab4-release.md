# MathHub MVP для лабораторної №4

Версію зафіксовано 26.11.2026 тегом **lab4-mvp** у репозиторії laanji/MathHub.

- Код версії: https://github.com/laanji/MathHub/tree/lab4-mvp
- Архів коду: https://github.com/laanji/MathHub/archive/refs/tags/lab4-mvp.zip
- Гілка подальшої розробки: main. Тег lab4-mvp залишається на початковому коміті.

## Що включено

Локальний модульний моноліт ASP.NET Core 8 / EF Core 8 / PostgreSQL 16 та React + TypeScript. Є реєстрація, вхід і вихід; ролі учня, батьків та адміністратора; батьківська активація; адаптивна діагностика й MathScore; підбір мінігруп, резерв і скасування; тестова оплата резерву; незалежна успішна/відхилена демооплата; приватна історія; каталоги трьох курсів та двох викладачів; редактор версій завдань. Дані зберігаються в PostgreSQL. Реальні гроші не списуються.

Міграції, seed-дані, фотографії та скрипти запуску входять до версії. Приватна .local, чинна БД, локальні паролі та встановлені залежності до Git не входять. Для першого запуску потрібні .NET SDK 8, Node.js 22+ та інтернет; кроки наведено в README.

## Відомі дефекти цієї версії

1. Одночасне оновлення авторизації у двох вкладках може повторно використати один refresh-токен і відкликати сесію. Потрібен повторний вхід; збережені дані не видаляються. Виправлення має координувати вкладки зі збереженням захисту від повторного використання токена.
2. Після переходу гостя з оплати конкретного курсу через реєстрацію або вхід втрачається початковий маршрут і вибір курсу. Курс можна вибрати знову; потрібне збереження маршруту повернення.

Ці дефекти зафіксовані, а не виправлені. Майбутні виправлення слід робити новими комітами, не переміщуючи тег Лаб4.

## Межі та перевірка

Результати локальної функціональної перевірки 25.11.2026 описано в docs/review.md і docs/report-audit.md. Під час фіксації версії перевіряються збірки й форматування; це не новий формальний звіт тестування. Навантажувальні цілі, повне покриття, production-готовність та виконання всіх FR/NFR не заявляються. Тести і їх валідація належать до Лаб6.

Відновлення пароля, зовнішня пошта, реальні платежі, уроки, домашні завдання та кабінет викладача ще не інтегровані. Індивідуальна робота ведеться в main; командні гілки й незалежне рев’ю не заявляються.

Звіт Лаб4 у Word/PDF і персональна пам’ятка зберігаються в SDLC поза репозиторієм. У звіті наведено також URL точного коміту, щоб перевірка не залежала від подальшого розвитку main.
