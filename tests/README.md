# Перевірки

Формальний набір unit/component/system/concurrency/load перевірок і звіт про покриття плануються для Лаб №6. Для поточної реалізації вже виконано локальну перевірку основних HTTP-сценаріїв на PostgreSQL 16 та користувацького шляху в браузері; результати — у `docs/review.md`.

Діагностичний математичний тест у кабінеті є функцією продукту, а не програмним тестом із Лаб №6. Збірки backend/frontend запускаються у GitHub Actions. Наявність цих перевірок не означає підтвердження всіх нефункціональних вимог.
