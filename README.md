# MathHub

Освітня платформа для діагностики знань і формування математичних мінігруп. Автор: Друченко Олексій Сергійович, ІК-41.

## Поточний етап

Лабораторна №4: базова структура коду. Це основа MVP; повний користувацький сценарій ще не інтегрований.

- Реалізовані доменні правила MathScore, 6 рангів / 18 підрангів, адаптивної сесії, резервів і місткості групи.
- API демонструє розрахунок рейтингу без створення офіційного результату учня.
- Контракти Identity та PostgreSQL-репозиторію підготовлені; реєстрація, JWT, EF Core, міграції та транзакційний запис будуть інтегровані на наступному етапі.
- Резерв — це Enrollment зі статусом Reserved, як у захищеній Лаб №2. Історія не має обмеження 5 записів; обмеження стосується зайнятих місць.
- Повна перевірка вимог і тестове покриття належать до Лаб №6.

## Запуск

Потрібні .NET SDK 8 та Node.js 22+.

```powershell
dotnet build MathHub.sln
dotnet run --project src/MathHub.Api
```

В іншому терміналі:

```powershell
cd src/MathHub.Web
npm ci
npm run dev
```

API: http://localhost:5080/health. Інтерфейс: http://localhost:5173. Vite проксіює /api на API.

## Структура

`src/MathHub.Api` — точка композиції та HTTP; `src/MathHub.SharedKernel` — спільні базові контракти; `src/Modules` — сім предметних модулів; `src/MathHub.Web` — React; `tests` — майбутні перевірки; `docs` — архітектура й рішення.

Domain містить бізнес-правила й не залежить від ASP.NET або БД. Application координує сценарії. Infrastructure додається разом із реальною реалізацією зовнішнього контракту; порожніх реалізацій, які удають працюючу БД або оплату, немає.
